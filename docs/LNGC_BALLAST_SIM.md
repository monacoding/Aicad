# 174K LNGC 발라스트 다이어그램 + 100회 시뮬레이션 보완 보고서

174,000 m³급 멤브레인 LNG 운반선 기준 발라스트 시스템을 그리고, 밸러스트 작업을
**100회 시뮬레이션**하면서 발견한 문제를 기능으로 보완했습니다.

재현:
```
npx tsx scripts/lngcsim.mts 100   # 100회 시뮬레이션 + 주석 다이어그램 렌더
```

## 1. 174K LNGC 발라스트 구성 (조사 기반)

- 4 화물창(멤브레인) 둘레 이중선체 사이드 WBT (P/S) + 선수/선미 피크(FPT/APT)
- WBT 총용량 ≈ **50,500 m³** (모델: FPT 3000, WBT1~4 P/S 5000~6000, APT 2500)
- 밸러스트 펌프 **2 × 3000 m³/h**, BWTS(필터+UV) 매칭, 듀트 킬 메인, 선외토출, 이덕터
- 다이어그램: 포트 WBT는 메인 위, 스타보드 WBT는 메인 아래 → 이중선체 배치를 표현

## 2. 시뮬레이션 모델 (`src/cad/ballastSim.ts`)

각 탱크의 종/횡 위치·용량을 모델링하고, 펌프 유량으로 목표 충수까지 채우며
**과도 힐(heel)·트림(trim) 모멘트**를 매 스텝 추적. 두 전략 비교:

- **naive**: 탱크를 임의 순서로 하나씩 채움(현장에서 흔한 비균형 작업)
- **paired(균형)**: P/S 쌍을 동시에 채워 횡모멘트 상쇄

무작위 밸러스트 조건(기준 충수 + 탱크별 지터) 100회.

## 3. 시뮬레이션이 드러낸 문제 → 보완

| 발견 | 보완 |
|---|---|
| naive 순차 작업 시 **과도 힐 큼**(P 탱크가 S보다 먼저 차면 기울어짐) | P/S 쌍 동시 충수(paired) → **최악 힐 −76%** |
| paired로 힐은 잡았으나 **트림이 오히려 악화**(쌍을 선수→선미 순으로 채워 종모멘트 누적) | 쌍 단위를 **선수/선미 양끝 교대**로 정렬 → 트림 최대 52.4→**25.2** (naive 38.3보다 우수) |
| 다이어그램에 작업 결과(충수)를 표시 못함 | 템플릿에 **탱크 충수율 주석**(레벨 바 + %) 추가, `add_rectangle/add_polyline`에 `fill`·`lineType` 보강 |
| 도면 연결성·용량 검증 부재 | 100회 전부 **overflow 0 / dry 0 / 도달불가 0** 검증 |

## 4. 결과 (100회)

```
max transient HEEL index (0..100, 낮을수록 좋음)
  naive  : avg 18.8  max 46.7
  paired : avg  4.9  max 11.4     ← 최악 힐 76% 감소
max transient TRIM index
  naive  : avg 17.8  max 38.3
  paired : avg 16.4  max 25.2     ← 교대 정렬로 트림도 개선
완료 시간(2펌프): avg 6.2 h
무결성: overflow 0 / dry 0 / unreachable 0  (양 전략 모두)
```

→ **균형(P/S 동시) + 선수·선미 교대 충수**가 힐과 트림을 동시에 낮춤. 이 결과가
   `scripts/out/lngc_ballast.png`에 대표(중량 밸러스트) 충수율로 주석됨.

## 5. 추가된 기능 (CAD 본체)

- 시스템 템플릿 `buildLngcBallastSystem(levels?)` — 자연어 "174k lngc 발라스트…"로 작도
- 밸러스트 시뮬레이터 모듈(탱크 모델·힐/트림·전략 비교)
- 엔티티 채움(`fill`)·선종류(`lineType`)를 사각형/폴리라인 연산에서 직접 지정

## 6. 남은 개선 후보

- 동적 복원성(GM) 기반 실제 힐 각도, 자유표면 영향 반영
- 디밸러스트(이덕터 스트리핑) 단계 시뮬레이션, 평형수 교환(BWE) 시퀀스
- 충수율 실시간 애니메이션 / 밸브 개폐 상태 연동, 라인 사이즈(유속 ≤3 m/s) 검증
