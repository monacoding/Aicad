# 선체 배관 시스템(Hull Piping) 전체 + 10회 개선 루프 보고서

표준 선박 선체/기계실 서비스 배관 16종을 학습해 모두 P&ID로 작도하고, 10회 개선
루프로 품질을 끌어올렸습니다. 재현:

```
npx tsx scripts/hull.mts            # 16종 빌드 + 검증(겹침/가독성/NaN)
npx tsx scripts/hull.mts --render   # + 16종 PNG 렌더
```

## 작도한 16개 계통

빌지 · 소화(SW) · 중앙 해수냉각 · 저온청수냉각(LT) · 고온자켓냉각(HT) · 연료유 이송 ·
연료유 서비스(청정) · 디젤유 · 윤활유 순환 · 위생청수 · 오수처리(STP) · 슬러지/유성빌지 ·
압축공기(시동/제어) · 증기·급수(보일러) · 유압(조타/갑판) · 불활성가스/질소(LNGC).

각 계통은 **선언적 사양(SystemSpec)** 하나로 정의되고, 공용 **자동 배치 빌더**
(`buildLinearSystem`)가 일관된 간격으로 P&ID를 생성 — 좌표를 손으로 찍지 않으므로
계통이 늘어도 겹침이 생기지 않습니다. 자연어로도 작도: "소화 시스템 그려줘",
"윤활유 시스템", "압축공기" 등.

## 10회 개선 루프 (드라이버: `scripts/hull.mts`)

| # | 개선 | 효과 |
|---|---|---|
| 1 | 16종 베이스라인 빌드 | 0 NaN, **겹침 4 계통**, 작은글자 128 |
| 2 | 분기 드롭을 **인라인 사이 간격 중점**에 배치(인라인 심볼 아래 겹침 제거) | 겹침 **4 → 0** |
| 3 | P&ID 정확도: **흐름 방향 화살표** + **라인 사이즈(DN250)** 헤더 표기 | 도면 규격성↑ |
| 4 | 가독성 지표를 **기하 객체 기준 span**으로 정정(긴 부제가 span 부풀려 태그를 거짓 '작음'으로 표시) | 작은글자 128 → 104 |
| 5 | **계기 버블 내부 텍스트**(심볼 내부, 시트 크기 무관)는 가독성 지표에서 제외 | 104 → **69** |
| 6 | 자연어 키워드 라우팅(가장 긴 트리거 우선)으로 16종 전부 도달 | 커버리지 확보 |
| 7 | 트리거 충돌 수정("급수" 모호성 → 보일러 급수로 귀속) | 커버리지 **18/18** |
| 8 | 장비 박스를 **라벨 폭에 맞춰 자동 크기** 조정(글자 잘림 방지) | 박스 라벨 정상 |
| 9 | 레이어 일관화(process/equipment/instrument) + 제목/부제 표준화 | 도면 일관성 |
| 10 | 전수 렌더 + 무결성 게이트(전 계통 0 NaN/빈 바운드/겹침) | 16/16 그린 |

## 최종 측정 (16 계통)

```
entities 917, NaN 0, emptyBounds 0, systems-with-overlap 0, tinyText 69
NL 키워드 커버리지 18/18 (충돌 0)
```

잔여 작은글자 69는 인라인 컴포넌트 하위 태그(0.45u) 등 본질적으로 컴팩트한 P&ID
주석으로, 확대 시 가독 — 정보성 지표로 둠.

## 추가/개선된 기능 (CAD 본체)

- `src/cad/hullSystems.ts` — 자동 배치 P&ID 빌더 + 16종 사양 레지스트리 + 자연어 매칭
- `add_rectangle`/`add_polyline`에 `fill`·`lineType` (장비 박스/참조선/레벨바)
- 흐름 방향 화살표·라인 사이즈 라벨·간격 보장 분기 배치(겹침 구조적 제거)

## 남은 개선 후보

- 라인 번호/구경 자동 채번(유속 ≤3 m/s 기반 사이징), 심볼 레전드·도면 타이틀블록
- 계통 간 인터페이스(공통 시 체스트/오버보드 매니폴드), 밸브 리스트/BOM 자동 추출
- 실제 ISA 계기 심볼(원+수평선=패널, 사각=PLC) 세분화
