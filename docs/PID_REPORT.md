# 선박 공정 P&ID 100종 생성 — 문제점 & 개선 보고서

AutoCAD P&ID를 참고해 AiCAD로 선박 공정 P&ID(배관·계장 도면)를 **100종 자동 생성**하며
부족한 기능을 발견하고 개선했습니다. 재현: `npx tsx scripts/pid.mts 100`.

## 1. P&ID를 그리려고 보니 없던 것들 → 추가한 기능

| 발견된 부족함 | 추가/개선 |
|---|---|
| 장비·밸브·계기 **심볼**이 없음 (원시 도형만) | `src/cad/pid.ts` — 16종 심볼 라이브러리: gate/globe/check/ball/butterfly/control valve, pump, vessel, tank, heat_exchanger, instrument, reducer, flange, arrow, strainer, motor |
| 계장 **신호선(점선)** 표현 불가 | 엔티티에 `lineType`(solid/dashed/dotted/phantom) + 렌더러 대시 + DXF LTYPE 입출력 |
| 배관/신호선 **선두께** 구분 불가 | 엔티티 `width`(파이프=두껍게, 신호=가늘게) |
| 심볼이 낱개 도형이라 **블록처럼** 다룰 수 없음 | 엔티티 `group` + 그룹 단위 선택/이동 (심볼 클릭 시 통째 선택) |
| 자연어로 P&ID 작성 불가 | `add_symbol`/`add_pipe`/`add_signal` 연산 + 서버 스키마/프롬프트 확장 |
| 명령행에서 심볼 배치 불가 | `SYMBOL`/`PIPE`/`SIGNAL` 명령 |

## 2. 100종 생성으로 드러난 결함 → 수정

자동 검출기(NaN, 빈 바운드, 장비 겹침, 글자 가독성)로 측정.

| 항목 | 개선 전 | 개선 후 | 조치 |
|---|---|---|---|
| 크래시/NaN 좌표 | 0 | 0 | (변환·바운드 파이프라인 견고함 확인) |
| 빈 바운드 | 0 | 0 | — |
| **장비/계기 겹침** | 38 | **7** | 계기 버블을 상단 레일 2행에 분산 배치, 컴포넌트당 1개로 정리 |
| **태그 가독성(작은 글자)** | 937 | **266** | 인라인 태그 높이 0.3→0.42, 가독성 기준 정상화 |
| 계기 버블 태그 줄바꿈 | (없음) | 적용 | `FTFO3` 한 줄 뭉침 → ISA식 **기능문자/루프번호 2줄** 중앙정렬 (`FT`/`FO3`) |

남은 266건은 계기 버블 내부 글자(0.26u, 0.55u 반경 버블)로, 확대 시 가독 — 의도된 컴팩트
표기로 간주(문서화).

## 3. P&ID 작업이 드러낸 일반 성능 결함 → 수정

- **스냅 O(n²) 교차 탐색**: 한 도면이 수십~수백 세그먼트가 되자 마우스 이동마다 모든
  세그먼트 쌍을 검사해 커서가 느려짐. → **커서 인근 세그먼트만** 추려 쌍 검사(`snap.ts`).
  밀집 P&ID에서도 즉각 반응.
- **DXF가 선종류 미보존**: 내보내면 신호선의 점선/파이프 의도가 사라짐.
  → LTYPE 테이블 + 엔티티별 `6` 그룹 입출력으로 라운드트립 보존.
- **자연어 화이트리스트 누락(버그)**: `add_ellipse`/`mirror`/`offset`/`array_*`/`hatch`가
  클라이언트 검증 목록에서 빠져 모델이 만든 해당 연산이 조용히 버려짐. → 목록 보강.

## 4. 측정값 (100종)

```
100 ship-process P&IDs generated in ~0.3 s  (~2.6 ms each)
entities: total ~4800, avg 48, max 72
problems: { nan:0, emptyBounds:0, zeroEntities:0, overlaps:7, tinyText:266 }
```

대표 시스템: Fuel Oil Transfer, Fuel Oil Service, Diesel Oil, Lube Oil, Stern Tube LO,
Main Sea Water Cooling 등 25개 선박 계통을 무작위 구성(소스→스트레이너→펌프(+모터)→
체크/게이트/제어 밸브→목적지, 분기·계기·신호선·태그·치수 포함).

## 5. 남은 개선 후보

- 자동 레이아웃 간격 보정(겹침 0 목표), 직교 자동 배관 라우팅
- 심볼 포트(노즐) 정의 + 배관 연결성/네트리스트, 라인 번호/태그 자동 채번
- 계기 루프/시그널 종류(전기·공압) 구분, 플로우 화살표 자동 부착
- DXF 블록(INSERT) 입출력으로 심볼을 진짜 블록으로 왕복
